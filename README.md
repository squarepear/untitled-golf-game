# Golf but the Hole Plays Too!

Have you ever wanted to play mini-golf? What about as the hole?

Well, with Golf but the Hole Plays Too, your dreams can come true!

## Required Tools

- Godot 4.6
- [`gdscript-formatter`](https://github.com/GDQuest/GDScript-formatter)
- [`just`](https://github.com/casey/just)

## Development

This project uses `just` to manage development tasks.

### Commands

- `just lint`: Check GDScript code style.
- `just format`: Format GDScript code.
- `just build [platform]`: Build the project. (defaults to web)
- `just dev`: Open the project in the Godot editor.
- `just play`: Run the game.
